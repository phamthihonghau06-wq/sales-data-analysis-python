# Sales Data Analysis with Python

## 📊 Introduction

This project analyzes retail sales data using Python and Pandas.

The goal is to explore sales performance, identify top-performing products,
analyze customers and markets, and generate useful business insights from transaction data.

## 🎯 Objectives

- Clean and prepare retail transaction data
- Analyze revenue trends
- Identify top-performing products
- Analyze revenue by country
- Analyze customer revenue
- Create data visualizations
- Generate business insights

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
